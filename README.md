**Chess Coach**

Chess Coach 10 giúp phân tích trận đấu từ chess.com:
+ Tìm và phân tích trận đấu theo user name trên chess.com
+ Phân tích trận đấu dựa trên PGN
+ Đánh giá và chấm điểm từng nước đi
+ Hỗ trợ chỉ ra quân treo, các quân kém tích cực
+ Phân tích từng lỗi và các thế cờ quan trọng trong ván bằng tiếng Việt
+ Hỗ trợ giao diện PC và Mobile, và nhiều tính năng khác...
