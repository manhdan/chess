**Chess Coach**

Chess Coach 9 giúp phân tích trận đấu từ chess.com:
+ Tìm và phân tích trận đấu theo user name chess.com
+ Phân tích trận đấu dựa trên PGN
+ Hỗ trợ chỉ ra quân treo, các quân kém tích cực
+ Phân tích từng lỗi và từng thế cờ quan trọng bằng tiếng Việt
+ Hỗ trợ giao diện PC và Mobile, và nhiều tính năng khác...
